# АИС «Справочник российских автомобилей» — материалы к отчёту

Учебный проект. PHP 8.4 + MariaDB 10.5+, клиент-серверная архитектура:
браузер (HTML/CSS/JS) ↔ PHP-приложение (сессии, PDO) ↔ удалённая MariaDB.
Внешнее C++17-приложение интегрируется через REST API (`public/api.php`, токен `X-API-Token`).

## 1. Диаграмма IDEF0 (контекст A-0 и декомпозиция A0)

Нотация IDEF0 приближена средствами Mermaid: вход слева, управление сверху,
механизмы снизу, выход справа (подписи стрелок сохранены).

### A-0 «Вести справочник российских автомобилей»

```mermaid
flowchart LR
    IN[Вход: справочные данные, JSON-файлы, запросы пользователей] --> A0
    CTRL[Управление: ТЗ, ролевая модель, политика паролей, ограничения БД] --> A0
    A0[A0: Ведение справочника российских автомобилей]
    MECH[Механизмы: пользователь/оператор/администратор, PHP-приложение, MariaDB] --> A0
    A0 --> OUT[Выход: карточки и справки PDF, отчёты, JSON-выгрузки, журнал действий]
